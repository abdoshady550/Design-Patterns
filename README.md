# 🎯 Design Patterns

A comprehensive C# repository showcasing classic design patterns through **simple, clear, and real-world inspired examples** rather than overly theoretical implementations.

## 📚 Overview

This repository is designed for developers who want to learn and understand design patterns by examining practical, real-world scenarios. Each pattern is implemented with clarity and simplicity in mind, making it easy to grasp the concept and apply it to your projects.

## 🏗️ Patterns Included

### Creational Patterns
- **Factory Pattern** - `Menu_Order.Factory_Pattern`
  - Real-world example: Menu ordering system
  - Learn how to create objects without specifying exact classes

- **Singleton Pattern** - `Singleton.Logging`
  - Real-world example: Centralized logging system
  - Ensure only one instance of a class exists

- **Prototype Pattern** - `Prototype.Demo`
  - Learn object cloning and creation through prototypes
  - Efficient object duplication

### Structural Patterns
- **Bridge Pattern** - `Bridge.Payment`
  - Real-world example: Payment systems
  - Decouple abstraction from implementation

- **Decorator Pattern** - `Decorator.IceCreamShop`
  - Real-world example: Ice cream shop customization
  - Add functionality to objects dynamically

### Behavioral Patterns
- **Mediator Pattern** - `Mediator.SmartHome`
  - Real-world example: Smart home automation
  - Define centralized communication between objects

### Enterprise Patterns
- **Service Locator** - `ServiceLocatorDemo`
  - Centralized service discovery and registration
  - Simplify dependency management

## 💻 Technology Stack

- **Language:** C# (.NET)
- **Solution File:** `Design Patterns.slnx`

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/abdoshady550/Design-Patterns.git
   cd Design-Patterns
   ```

2. Open the solution file in Visual Studio:
   ```bash
   Design Patterns.slnx
   ```

3. Explore each pattern folder to understand the implementation
4. Review the code structure and comments for detailed explanations

## 📖 How to Use

- Each folder represents a specific design pattern
- Inside each folder, you'll find:
  - Implementation of the pattern
  - Real-world scenario examples
  - Clear, commented code
  - Usage demonstrations

## 🎓 Learning Path

1. Start with **Creational Patterns** to understand object creation
2. Move to **Structural Patterns** to learn composition and relationships
3. Explore **Behavioral Patterns** to master object interaction
4. Review **Enterprise Patterns** for advanced architectural concepts
